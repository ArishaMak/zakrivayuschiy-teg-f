Закрывающий тег
Описание проекта:
"Закрывающий тег" — это финальный проект модуля вёрстки в курсе Fullstack Developer от Yandex Practicum.
Проект сочетает статическую верстку, адаптивный дизайн, CSS-анимации и интерактивные элементы. Карточки с изображениями, фильтрами и анимированным сердечком (лайк), модальное окно для "сохранения на память" и градиентный фон в стиле сетки. Всё сделано с акцентом на семантику, доступность.

Интерактивные элементы:
Кнопка "Like" с анимированным SVG-сердечком (hover, active, клик с масштабированием и искрами).
Модальное окно (dialog) для "Сохранить на память" с backdrop и кнопкой "ОК".
Эффекты на кнопках: фокус с тенью, hover с псевдоэлементом (difference blend-mode для смены цвета текста).

Визуальные эффекты:
Фон: Множественный градиент (repeating-linear + linear) для сетки, фиксированный при скролле.
Фильтры: Уникальные CSS-фильтры (включая множественные) на 7+ изображениях для передачи эмоций.
Анимации: Переходы fill/opacity в SVG, @keyframes для масштаба и искр (ease-in, задержки для последовательности).

Адаптивность: Резиновый дизайн с clamp(), медиазапрос для 375px.
Доступность: Фокус-стили (focus-visible), mnemonics для < >, @supports для text-stroke.

Технологии
Верстка:
HTML5 (семантика, dialog, symbol/use в SVG).
CSS3 (Grid/Flexbox, clamp(), variables, mix-blend-mode, filter, backdrop, @keyframes, @supports).


Шрифты: Inter (variable, weights 100-900), PressStart2P (акцентный).

Инструменты:
Figma (макет, экспорт SVG/изображений).
Git/GitHub (версионный контроль, Pages для деплоя).


Оптимизации: Оптимизированные фавиконы (ico, SVG, PNG для iOS), инлайн-SVG для анимаций.

Без JS-библиотек — чистый vanilla для простоты.
